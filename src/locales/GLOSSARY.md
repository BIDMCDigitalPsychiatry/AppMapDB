# MINDapps translation glossary (EN → FR / DE)

Shared by everyone who drafts or reviews the interface translations (people
and models), so the same term is always translated the same way. Catalogs:
`fr.json` and `de.json`. The keys are the English text. `source.json` lists
the files where each string appears, which gives you its context.

## Style
- **French:** neutral standard (international) French, understandable in France and Canada. Formal
  *vous*. French typography: a non-breaking space before `: ; ? !`, and « guillemets » for quotes.
  Avoid anglicisms when a common French term exists (*courriel* is fine, but *e-mail* is also acceptable,
  so pick one: **e-mail**).
- **German:** formal *Sie*, standard German (Germany). Use compound nouns naturally. Use gender-inclusive
  forms only where they're natural; otherwise use neutral wording (e.g. *Bewertende* rather than
  *Bewerter/innen* where it reads well).
- Keep {{placeholders}} exactly. Keep brand names unchanged: MINDapps, MIND, App Store, Google Play,
  iOS, Android, PHQ-9, GAD-7, HIPAA, Flesch-Kincaid.
- Match the source's tone: plain, friendly, clear. Buttons are short imperatives. Don't add words that
  aren't in the English.
- Keep sentence-case and capitalization patterns comparable (German nouns are capitalized, of course).
- UI space is limited. Prefer the shorter natural option for buttons, tabs and filter chips, because
  German text runs long.

## Do not translate
App names, company names, store descriptions, rater reviews, news posts, comments, people's names and emails.
These never appear in the catalogs.
